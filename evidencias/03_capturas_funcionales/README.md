# Capturas funcionales

Esta carpeta se usará para guardar evidencias visuales de los flujos principales de Hyper Distric. Las capturas deben tomarse manualmente desde el navegador, idealmente con la consola sin errores visibles y mostrando la URL cuando sea útil.

## Recomendaciones generales

- Usar nombres claros y ordenados.
- Guardar las capturas en la carpeta del módulo correspondiente.
- Evitar mostrar contraseñas, tokens o datos sensibles.
- Para pruebas de compra, registrar también stock antes y después.
- Si una prueba falla, guardar captura del error y anotar el caso en `07_mejoras_correcciones/bugs-detectados.md`.
